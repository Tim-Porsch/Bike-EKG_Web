        Browser und Verbindung
        
    Unterstützt werden Chrome/Edge unter Windows und macOS sowie Chrome unter Android.
          Unter Linux kann eine zusätzliche Freischaltung von Web Bluetooth erforderlich sein.
          Firefox und Safari werden nicht unterstützt.
    
        
    Web Bluetooth erfordert einen sicheren Kontext, üblicherweise HTTPS oder localhost.
          Hinweise zur lokalen Bereitstellung stehen in der README.
    
        
    Die Kommunikation erfolgt lokal über den Nordic UART Service (NUS).
          Die Anwendung überträgt keine Konsolendaten an einen Server und lädt keine externen Bibliotheken.

          Darstellungsfilter
        
    
          
    Bandpass & Notch
    
          
    
            i
            
    
              
    LP (Tiefpass): Butterworth-IIR 2. Ordnung, dämpft hohe Frequenzen. Die Grenzfrequenz liegt bei −3 dB.
    
              
    HP (Hochpass): Butterworth-IIR 2. Ordnung, dämpft Gleichanteil und langsame Baseline-Schwankungen. Grenzfrequenz bei −3 dB.
    
              
    Notch (Bandsperre): IIR-Biquad 2. Ordnung gegen eine schmale Störfrequenz, etwa 50 Hz Netzbrummen. Güte Q bestimmt die Breite (ungefähr f₀/Q); höheres Q bedeutet schmalere Sperre.
    
              
    Berechnung über alle Messpunkte in der Reihenfolge HP → LP → Notch, mit gespeicherter bzw. geschätzter Abtastrate. Kausal, einmal vorwärts: Phasenverschiebungen und Einschwingeffekte sind möglich. An Datenlücken werden die Zustände mit konstantem Anfangswert neu initialisiert; Lücken werden nicht überbrückt. Keine medizinische Auswertung.
    
              
    Nur Ansicht und PNG werden gefiltert. Originaldatei und CSV-Download bleiben unverändert. Während der SD-Übertragung sind die Filter gesperrt.
    
            
    
          
    
        
    
        
    
          
    
          
     
    
          
     
    
          
      
    
          
    
          
    
            
    
              
    QRS-Verstärkung
    
              
    
                i
                
    
                  
    Nach HP → LP → Notch: feste kausale 5-Punkt-Ableitung, Quadrierung und gleitender Mittelwert über das eingestellte Zeitfenster (Standard 150 ms, auf ganze Samples gerundet).
    
                  
    Ableitung: fₛ/8 · (x[n] + 2x[n−1] − 2x[n−3] − x[n−4]). Danach wird quadriert und über die letzten N Samples gemittelt. An Datenlücken werden Ableitung und Integrator zurückgesetzt; fehlende Anfangswerte der Integration zählen als null.
    
                  
    Ergebnis ist eine QRS-Energiekurve in (Counts/s)², kein EKG-Rohsignal. Ableitung und Integration verursachen Verzögerung; Zeitstempel werden nicht verschoben. Keine automatische R-Zacken-Erkennung und keine vollständige Pan-Tompkins-Auswertung.
